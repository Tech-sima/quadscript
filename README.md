# Quadscript — сайт и backend на Next.js

## Как работает
- Фронтенд: `/pages/index.js` — React-интерфейс с интерактивными кнопками и статусами ботов
- Backend: `/pages/api/bots.js` — серверная логика для работы с Supabase
- Статика: `/public/style.css` — стили
- Переменные окружения: `.env.local` (ключи Supabase)

## Деплой на Vercel
1. Загрузите весь проект на Vercel (корень должен содержать папки `pages`, `public`, файл `.env.local`)
2. Vercel автоматически определит Next.js и задеплоит сайт с backend
3. Всё будет работать без ошибок: интерактив, сервер, база данных

## Использование
- Введите список ботов слева, сохраните
- Проверьте статусы или покажите "Мои боты"
- Клик по свободному боту — он становится "занятым" для вас

## Настройка Supabase
- В консоли Supabase создайте таблицу `bots` с колонками:
  - `name` (text, primary key)
  - `status` (text)
  - `loaded_by` (text)
- Вставьте ключи в `.env.local`
