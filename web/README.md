# Проект: Статус юзер-ботов

## Описание
Веб-страница с черно-голубым дизайном, состоящая из двух колонн:
- Левая колонна: ввод списка юзер-ботов (по одному на строку).
- Правая колонна: отображение статуса каждого бота — "занят" или "свободен".

Статусы синхронизируются между всеми пользователями в реальном времени через Supabase.

## Развертывание на Vercel

1. Скопируйте содержимое папки `web` в отдельную директорию.
2. В файле `app.js` вставьте свои параметры `SUPABASE_URL` и `SUPABASE_ANON_KEY` из консоли Supabase.
3. Зайдите на [vercel.com](https://vercel.com/) и создайте новый проект, выбрав папку с файлами.
4. Убедитесь, что корневой файл — `index.html`.
5. Деплойте проект.

## Настройка Supabase
1. Перейдите в [Supabase Console](https://app.supabase.com/) и создайте новый проект.
2. Перейдите в раздел Table Editor и создайте таблицу `bots` со следующими колонками:
	- `name` (text, primary key)
	- `status` (text)
	- `loaded_by` (text)
3. Перейдите в раздел Project Settings → API и скопируйте значения `URL` и `anon key`.
4. Вставьте их в файл `app.js` вместо `YOUR_SUPABASE_URL` и `YOUR_SUPABASE_ANON_KEY`.

## Использование
- Введите список ботов слева, нажмите "Сохранить список".
- В правой колонне отображаются статусы ботов.
- Клик по "свободному" боту — он становится "занятым" для других пользователей.
- Статусы обновляются в реальном времени для всех пользователей.
